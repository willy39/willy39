## 아트 디렉션 정하기

`concept.md`의 구간마다 아래 다섯 가지를 정한다. 쇼릴이면 구간마다 다른 답이 나와야 한다. 한 영상 안에서 같은 바탕색과 서체를 되풀이하면 작업 한 편을 길게 늘인 것으로 보인다. 구간 안에서는 정한 값을 일관되게 지킨다.

| 정할 것 | 고르는 방법 |
| --- | --- |
| 매체 | DOM 타이포, SVG 선, 캔버스 2D(입자·절차적 그림), WebGL(셰이더·3D), 사진·생성 이미지, 또는 이들의 조합. 구간마다 매체를 바꾸면 표현 범위가 바로 보인다 |
| 팔레트 | 주제에서 뽑는다: 브랜드 공식 색, 사진의 색, 가상 의뢰의 업종과 시대. 밝은 바탕, 원색 대비, 단색, 흑백도 후보다. 어두운 바탕은 이유가 있을 때 고른다 |
| 서체 | `new_project.py`가 준비하는 서체(Pretendard 가변 45~920, Noto Serif KR, Black Han Sans, Anton, JetBrains Mono, 로컬에 있으면 Paperlogy·에이투지체) 밖의 Google Fonts 서체(모두 OFL)도 `new_project.py <프로젝트> --fonts "Hahmlet:wght@300;900" --fonts "Gowun Batang:wght@700"`로 더한다. 굵기는 범위가 아니라 `;`로 나열한다. 렌더 로그의 폰트 목록에서 실제로 불렸는지 확인한다 |
| 움직임의 성격 | 무게(가볍게 튀는가, 무겁게 떨어지는가), 재질(종이, 액체, 금속, 빛, 천), 속도 분포(대부분 빠르고 한 번 느린가, 그 반대인가). 이 답이 이징과 타이밍을 정한다 |
| 질감 | 평면, 하프톤, 디더, 픽셀, 유리, 잉크 번짐, 필름 그레인 등. 한 질감을 모든 구간에 덮지 않는다 |

실존 브랜드가 주제면 팔레트와 서체는 공식 자료에서 가져오고, 매체와 움직임으로 구간을 나눈다.

## 뻔한 화면

아래 요소는 이 스킬의 이전 기본값이었고, 평가 실행에서 스킬을 쓴 영상과 쓰지 않은 영상 모두에 함께 나왔다. 주제가 달라도 영상이 비슷해 보인 원인이다.

- 어두운 바탕 + 강조색 하나(금색·시안·주황) + 비네트 + 필름 그레인
- 모서리 브래킷, 타임코드, `CH.01 / TITLE` 챕터 라벨, 하단 진행 바
- 화면마다 작게 넣는 영문 대문자 모노체 라벨
- 큰 히트마다 같은 슬램(1.3~2배 확대·블러에서 착지) + 화면 흔들림 + 섬광
- 가운데 정렬 제목 + 부제 카드가 차례로 바뀌는 구성
- 빈 배경을 채우려고 까는 원근 격자 바닥과 떠다니는 먼지
- 터미널 타자 + 깜빡이는 커서로 시작하는 오프닝
- 레터박스가 열리는 오프닝, 렌즈 플레어
- 모든 장면을 같은 비율로 천천히 미는 확대

이 요소들을 금지하지는 않는다. 콘셉트가 요구하면 의도해서 쓰고 그 이유를 `concept.md`에 적는다. 이유 없이 들어가 있으면 뺀다. 스타일 프레임과 비평 단계에서 이 목록으로 화면을 확인한다.

## 움직임 원칙

움직임의 질은 정지 프레임으로는 드러나지 않는다. 핵심 순간은 0.1초 이하 간격의 프레임 띠로 뽑아 프레임마다 이동량이 어떻게 변하는지 본다(`qa.md`의 "비평").

| 원칙 | 하는 일 |
| --- | --- |
| 예비 동작 | 크게 움직이기 전에 반대 방향으로 3~6프레임 작게 물러난다. 결과가 큐 프레임에 보이도록 예비 동작은 큐 앞에 둔다 |
| 넘침과 안착 | 멈출 때 목표를 지나쳤다 돌아온다(`ease.outBack`, `spring`). 무거운 것은 덜 넘치고, 가벼운 것은 여러 번 튄다 |
| 겹치는 동작 | 한 덩어리의 부분(음절, 자모, 획, 조각)이 같은 프레임에 출발하고 도착하지 않는다. 출발은 2~4프레임씩 어긋나게 둔다 |
| 후속 동작 | 주 동작이 끝난 뒤 딸린 요소(그림자, 잔상, 매달린 선, 입자)가 늦게 멈춘다 |
| 2차 동작 | 주 동작이 만드는 결과를 그린다. 글자가 떨어지면 바닥이 눌리고, 획이 그어지면 잉크가 번진다 |
| 간격 | 같은 거리라도 프레임마다 이동량이 어떻게 변하는지가 성격을 정한다. 모든 요소를 기본 이징 하나로 움직이지 않는다. `kf`·`spring`이나 직접 쓴 함수로 요소마다 곡선을 정한다 |
| 시선 이어 주기 | 한 구도의 움직임이 끝나는 자리에서 다음 구도의 첫 움직임이 시작된다. 컷 직전 시선이 있던 곳에 다음 화면의 주인공을 둔다 |
| 깊이 | 전경·중경·배경을 다른 속도로 움직인다. 카메라가 움직일 때 원근이 생기도록 레이어를 나눈다 |
| 물리 | 낙하, 감쇠 진동, 공기 저항은 닫힌 식으로 계산한다(`techniques.md` T04·T14). 누적이 필요한 시뮬레이션은 setup에서 미리 계산한다(`engine.md`) |

출발값은 아래와 같다. 아트 디렉션이 요구하면 바꾼다.

| 항목 | 출발값 |
| --- | --- |
| 등장 | 0.35~0.7초, 이동은 크게 시간은 짧게. 느리고 작은 움직임은 슬라이드처럼 보인다 |
| 퇴장 | 0.25~0.4초. 컷 0.1초 전에 끝낸다 |
| 여러 요소 | 0.03~0.08초 간격 스태거 |
| 흔들림 | 진폭 12~18px, 감쇠 0.4초. 큰 사건에만 |
| 숫자 | 카운트업 1.2~1.8초 outQuart. 작은 값은 굴리지 말고 한 번에 찍는다(중간값이 실제 값처럼 읽힌다) |
| 큐 동기 | 핵심 사건은 큐 ±3프레임 안에 보인다 |
| 마지막 프레임 | 마지막 10프레임에 새 정보를 넣지 않는다 |

## 리듬

- 실수로 멈춘 화면이 없게 한다. 1초 넘게 아무것도 변하지 않는 구간은 의도한 정지(음악 정지, 숨 고르기, 엔드카드)일 때만 둔다. `motion_check.py`가 이런 구간을 시각과 함께 알려 준다. 기준(멈춘 화면 비율, 큰 움직임 p90)은 20초 이하 8%·15, 60초 이하 20%·7, 그보다 긴 영상 35%·6이다.
- 한 구도가 2마디(120 BPM에서 4초)를 넘으면 그 안에서 무엇이 바뀌는지 확인하고, 의도한 정지가 아니면 구도를 바꾸거나 새 사건(등장, 재배치, 카메라 이동)을 넣는다.
- 사건의 크기와 간격에 대비를 둔다. 몰아치는 구간과 비우는 구간을 음악 구조에 맞춰 정하고, 큰 사건 앞은 비우거나 줄인다. 모든 박에 같은 크기의 사건을 두면 리듬이 평평해진다.
- 퇴장도 움직임이다. 투명도만 내리지 말고 다음 구도로 밀거나, 변형하거나, 다음 구도의 요소가 되게 한다. `REEL.inout`은 그중 한 방법이다.
- 화면이 소리에 반응하게 만들 때 쓰는 값: `REEL.level`(음량 곡선), `REEL.pulse`(히트), `REEL.TL.music.beats`.
- 검은 배경 위 글자만 있는 화면은 확대를 넣어도 멈춘 것으로 보인다. 그 구간의 아트 디렉션에 맞는 배경 움직임을 만든다.

## 한글 타이포그래피

### 한글을 재료로 쓰는 방법

한글은 자모가 네모꼴 안에서 조립되는 구조라서, 라틴 문자로는 할 수 없는 움직임이 나온다. 아래는 엔진에서 해 본 방법이다.

- 자모 분해·조립: 음절을 초성·중성·종성 영역으로 잘라 따로 움직인다(`techniques.md` T05). 음절 코드를 계산하면 ㅎ → 하 → 한처럼 타자 과정을 보여 줄 수 있다.
- 획 그리기: fontTools로 서체 윤곽을 뽑아 SVG path로 만들고 `stroke-dashoffset`으로 그린다(T05의 "정밀한 방법").
- 가변 굵기: Pretendard Variable의 `wght`를 글자마다 박에 맞춰 바꾼다(T06).
- 네모꼴 격자: 음절을 칸에 넣어 타일처럼 뒤집고 회전한다(T10).
- 입자·3D: 글자를 픽셀에서 점으로 뽑거나(T04), 캔버스에 그린 글자를 WebGL 텍스처로 쓴다(`engine.md`).
- 세로쓰기(`writing-mode: vertical-rl`), 받침만 떨어뜨리기, 같은 음절을 여러 서체로 바꿔 끼우기.

### 크기와 규칙

| 용도 | 크기(1080p 기준) | 규칙 |
| --- | --- | --- |
| 디스플레이 헤드라인 | 120~260px | 900 굵기면 자간 -0.03~-0.05em, 행간 1.05, 두 줄 이하 |
| 1~3자 단어·이름 | 300~480px | 화면을 가득 채워도 된다 |
| 거대 숫자 | 200~400px | `tabular-nums`, 단위는 본문 서체로 작게 |
| 본문·설명 | 40~64px | 화면 한 장에 20자 안팎 |
| 자막 | 38~44px | 하단 64~104px, 그림자 2겹 |
| 최소 크기 | 읽어야 하는 글자 32px, 부제·CTA 48px | 엔드카드 CTA를 가장 작은 글자로 두지 않는다 |

- `word-break: keep-all`을 쓴다(템플릿에 들어 있다). 어절 중간에서 줄이 바뀌거나 조사만 다음 줄로 떨어지면 줄을 직접 나눈다(`<br>`).
- 영문 디스플레이 서체(Anton, JetBrains Mono)에는 한글이 없다. 폰트 스택 끝에 한글 서체를 둔다. 템플릿 변수(`--num`, `--mono`)에는 이미 들어 있다.
- 마스크 리빌은 `split(el, 'char', {mask: true})`를 쓴다. 마스크 여백(.12em/.18em)이 있어야 받침·윗점이 잘리지 않는다.
- 마스크 안 글자에 `text-shadow`를 주면 사각형 잔상이 생긴다. 글로우는 같은 글자를 blur 한 복제 레이어로 따로 그린다.
- 그라디언트 글자(`background-clip: text`)는 transform이 걸린 자식 span에서 사라진다. 글자마다 그라디언트를 걸고 `background-position`을 이어 붙인다.

## 레이아웃과 안전 영역

16:9 (1920×1080):

- 본문 안전 영역 x 120~1800, y 120~900
- 화면 가장자리에 붙는 요소는 46px 안쪽
- 자막 영역 y 940~1040. 자막이 있는 영상은 그래픽을 y 900 아래로 내리지 않는다
- 카메라가 움직이는 장면에서도 자막 영역은 비워 둔다. 완성 MP4에서만 겹침이 드러난 사례가 있다

9:16 (1080×1920):

- 위 250px(앱 상단 UI)와 아래 420px(캡션·버튼)를 비운다(번인 자막은 아래 440px에 놓인다)
- 헤드라인은 화면 폭의 80% 이내, 한 줄 6~8자
- 가로 사진은 가상 카메라로 확대해 피사체를 따라간다(scale 2 안팎)

의도한 크롭(화면 밖으로 넘치는 거대 글자)은 안전 영역 규칙의 예외다.

## 전환

전환은 두 구간을 잇는 논리다. 앞 구간의 형태, 색, 움직임 방향 가운데 하나를 다음 구간이 이어받게 설계한다. 같은 전환을 세 번 연속 쓰지 않는다.

| 전환 | 방법 | 어울리는 곳 |
| --- | --- | --- |
| 매치 컷 | 앞 장면의 도형(점·원·선·글자)이 같은 자리·크기로 다음 장면의 다른 요소가 된다(T16) | 서로 다른 구간을 잇는 곳 |
| 형태 변형 | 앞 요소가 변형되며 다음 구간의 첫 요소가 된다(입자 재형성 T04, 숫자→글자 모핑 T03) | 매체가 바뀌는 곳 |
| 줌 스루 | 화면 속 한 점(글자 구멍, 화면, 눈동자)을 inExpo로 7~9배 확대 | 구간 안쪽으로 들어갈 때 |
| 마스크 리빌 | `clip-path: inset()`·`circle()`이 열린다 | 사진·카드 등장 |
| 색면 와이프 | 색 면이 들어왔다가 반대쪽으로 빠진다(0.2+0.3초) | 색이 다른 두 구간 사이 |
| 슬랫 | 세로 막대가 차례로 열리고, 다 열리면 한 장의 이미지로 바꿔 이음선을 없앤다 | 사진 몽타주 |
| 휩 팬 | 들어오는 쪽 4프레임 이동 + 가로 블러(T18) | 같은 방향으로 이어지는 움직임 |
| 푸시 | 다음 장면이 밀고 들어오며 앞 장면은 -35% 이동 | 목록·순서 |
| 정지 + 암전 | 음악 정지와 함께 0.5~1초 빈 화면 | 전환점·반전 |
| 풀 백 | 카메라가 뒤로 빠지며 전체 구조가 드러난다 | 시스템 설명의 마무리, 구간 전체를 모아 보여 줄 때 |

## 섬광 안전

화면 10% 이상이 밝기 0.1 넘게 오르내리는 변화를 1초에 3회 이하로 둔다(광과민성). 어두운 배경 위 섬광은 opacity 0.15 이하, 0.12~0.25초로 쓴다. 자세한 규칙은 `techniques.md`의 "공통 규칙"과 T20에 있다.

## 하지 않을 것

- 제목 + 불릿 목록 화면(슬라이드처럼 보인다), 읽는 시간(한글 초당 6~8자)보다 긴 글을 한 화면에 두는 것
- 숫자·사실 없는 형용사 카피("혁신적인", "획기적인")
- 다른 회사 로고를 그리거나 실존 인물 얼굴을 합성하는 것
- 이모지(아이콘은 SVG로 그린다)
- 화면 전체에 blur 필터를 여러 겹 거는 것(렌더가 몇 배 느려진다)
